Detailed Description

template<class TEstimator, typename TSplitter>
class DGtal::ParallelIIEstimator< TEstimator, TSplitter >

Run an Integral Invariant estimator in parallel.

This class is meant as an almost perfect replacement of other IIEstimator. The only difference is the constructor which needs the number of threads.
